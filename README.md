## Описание проекта
Приложение разработано в рамках лабораторной работы №3 по курсу мобильной разработки для ОС Android.

Включает выполнение двух практических заданий:
1. **Механизмы локального хранения данных**:
   - **SharedPreferences**: сохранение строковых заметок по ключу `saved_note` с помощью метода `apply()`, загрузка с обработкой отсутствия данных и полная очистка записи.
   - **Файловая система (`filesDir`)**: сохранение заметок в приватный файл `my_note.txt` с использованием методов `writeText()` и `readText()`.
   - Проверка существования файла (`file.exists()`) и обработка исключений ввода-вывода через блок `try-catch`.
   - Валидация пользовательского ввода (запрет сохранения пустых заметок) с отображением уведомлений `Toast`.

2. **Работа со списками через RecyclerView**:
   - Отдельный экран (`RecyclerActivity`) со списком элементов на базе `RecyclerView` и `LinearLayoutManager`.
   - Кастомный адаптер `NotesAdapter` и `ViewHolder` с разметкой карточки `item_note.xml`.
   - Динамическое добавление заметок через `notifyItemInserted()`.
   - Удаление элементов из списка по кнопке внутри карточки с вызовом `notifyItemRemoved()`.

## Сборка и запуск
- Минимальная версия Android SDK: API 24 (Android 7.0)
- Целевая версия Android SDK: API 37
- Язык разработки: Kotlin
- Готовый установочный файл приложения: `app-debug.apk` в корне репозитория.
